# Symbol Table Generator

## 📌 Overview
This project is a Symbol Table Generator developed as part of SSCD (System Software and Compiler Design).  
It generates a symbol table from the given source code by identifying identifiers, keywords, operators, and other tokens.

---

## 🚀 Features
- Generates symbol table for given input program
- Stores identifier name, type, address, and size (if applicable)
- Supports basic compiler design concepts

---

## ⚙️ Tech Stack
- C / C++ (depending on implementation)

---

## ▶️ How to Run
1. Compile the program:
gcc symboltable.c -o symboltable


2. Run:

./symboltable
